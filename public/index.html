Parallel 2D Heat Diffusion: Mathematical & HPC Foundations

Finite Difference Method, OpenMP Stencils, and Roofline Scaling

1. Governing Partial Differential Equation (PDE)

Fourier's 2nd Law of Heat Conduction in two dimensions:

$$\frac{\partial u}{\partial t} = \alpha \left( \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} \right)$$

Where $u(x, y, t)$ is temperature and $\alpha$ is thermal diffusivity.

2. 5-Point Finite Difference Stencil

Using forward time, central space (FTCS) finite differencing on a square grid ($\Delta x = \Delta y = h$):

$$u_{i,j}^{t+1} = u_{i,j}^t + \frac{\alpha \Delta t}{h^2} \left( u_{i+1,j}^t + u_{i-1,j}^t + u_{i,j+1}^t + u_{i,j-1}^t - 4u_{i,j}^t \right)$$

CFL Stability Criterion: For explicit 2D numerical schemes, stability requires $r = \frac{\alpha \Delta t}{h^2} \le 0.25$. Exceeding 0.25 causes numerical explosions.

3. Domain Decomposition & OpenMP Mapping

The 2D matrix is decomposed across $p$ threads using horizontal row-slabs:

#pragma omp parallel num_threads(p)
{
    // Persistent thread pool avoids fork/join overhead
    for (int step = 0; step < steps; ++step) {
        #pragma omp for schedule(static)
        for (int y = 1; y < H - 1; ++y) {
            #pragma omp simd
            for (int x = 1; x < W - 1; ++x) {
                // Stencil computation with AVX2 SIMD
            }
        }
    }
}

4. Amdahl's Law vs Memory Saturation

Amdahl's law defines maximum theoretical speedup based on the parallel fraction $P$:

$$S(p) = \frac{1}{(1 - P) + \frac{P}{p}}$$

In memory-bandwidth-bound stencils, performance often levels off early because multiple CPU cores compete for the shared DDR memory bus.
